# Rota Fácil SP

"Crie uma aplicação web chamada RotaFacil SP para gestão de cargas e fechamento diário de frota própria. O sistema deve ter: (1) mapa interativo com Leaflet/OpenStreetMap focado em São Paulo com marcadores de entregas por CEP; (2) tela de despacho com seleção de veículo, motorista e ordenação de paradas por proximidade; (3) tela de lançamento de NF-e; (4) módulo de fechamento de turno registrando KM final do hodômetro e baixa nas NFs (Entregue ou Devolvida com motivo). Use Supabase para salvar as tabelas de veículos, motoristas, notas e rotas."
